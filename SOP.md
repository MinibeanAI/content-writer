# Content Writer SOP

1. Confirm the article brief and source scope.
2. If research is wanted, name the proposed query and sources; wait for approval before looking online.
3. Produce an outline for the user to approve.
4. Draft in chat, preserving a clear distinction between fact, opinion, and placeholder.
5. Offer local style references or an image brief; do not obtain or modify images.
6. Return Markdown or an HTML preview in chat.
7. Save one local file only after the user gives an explicit destination and approves the final text.

The workflow never posts, uploads, or shares the article.
